# Paint Alkalmazás Kaleidoszkóp Móddal

Egy egyszerű, de funkciókban gazdag paint alkalmazás böngészőben, speciális kaleidoszkóp móddal.

## Funkciók

### Rajzolási eszközök
- **Szabadkézi rajzolás**: Ecset eszköz folyamatos rajzoláshoz
- **Téglalap**: Téglalapok rajzolása
- **Kör**: Körök rajzolása
- **Radír**: Rajzolt elemek törlése

### Testreszabás
- **Színpaletta**: 12 előre definiált szín
- **Egyéni színválasztó**: Bármilyen szín kiválasztása
- **Ecsetméret**: 1-50 pixel közötti méret beállítása

### Speciális funkciók
- **Kaleidoszkóp mód**: A rajzolt vonalak szimmetrikusan ismétlődnek több tengely körül
- **Tengelyek száma**: 2-12 tengely közötti beállítás (alapértelmezett: 6)
- **Visszavonás/Újra**: Akár 50 lépés visszavonása és újra alkalmazása
- **Vászon törlése**: Teljes vászon törlése egy kattintással

## Használat

1. Nyisd meg az `index.html` fájlt egy modern böngészőben
2. Válassz egy eszközt (ecset, téglalap, kör, radír)
3. Válassz színt a palettáról vagy az egyéni színválasztóval
4. Állítsd be az ecsetméretet
5. Rajzolj a vásznon!

### Kaleidoszkóp mód használata

1. Kapcsold be a "Kaleidoszkóp mód" kapcsolót
2. Állítsd be a tengelyek számát (2-12)
3. Rajzolj a vásznon - a vonalaid szimmetrikusan ismétlődnek a központ körül!
4. Próbáld ki különböző színekkel és ecsetméretekkel!

## Technikai részletek

- **HTML5 Canvas** API a rajzoláshoz
- Reszponzív dizájn
- Érintőképernyő támogatás
- 1000x600 pixel vászon méret
- Teljes undo/redo történet

## Tippek

- A kaleidoszkóp mód téglalapokkal és körökkel is működik!
- Használj vékony ecsetet (1-3px) részletes mintákhoz
- Próbálj ki különböző tengelyszámokat: 3, 4, 6, 8 vagy 12
- Az undo funkció akár 50 lépést is visszavonhat

Jó rajzolást! 🎨
